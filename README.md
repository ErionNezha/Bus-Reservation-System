# Bus Reservation System (C++)

Sistem rezervimi autobusësh në C++ — regjistrim autobusësh, rezervim vendesh (32 vende/autobus) dhe listë udhëtarësh.

`C++`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Bus-Reservation-System/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Kompilo me `g++ SBRSC.cpp -o bus` dhe ekzekuto `./bus`.
